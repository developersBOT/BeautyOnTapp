## Decision logic

- Waste severity ladder (sqr-negatives-pipeline): HIGH = cost >=R200 & 0 conv (act first); MEDIUM = R100-<R200 & 0 conv; LOW = <R100 & impressions >=1000 & 0 conv (thematic pre-empt); plus any Cost/conv > R300. Below all four = noise, skip. Reinforce with config CPA ceilings: BoT R167, general R300.
- Bucket -> match type + target level: Bucket 1 irrelevant = EXACT, account-wide. Bucket 2 wrong-intent = EXACT if specific / PHRASE if pattern, campaign- or ad-group-level (negate only where the click is paid, so SEO/AEO still benefits). Bucket 3 competitor = EXACT, account-wide. Bucket 4 ambiguous = do NOT negate; T review list (or a phrase-match negative only if 0 conv across 100+ clicks).
- Never negate a broad product-type ('face wash', 'face serum', 'face cream', 'review', 'vs') or any stocked brand — if the pipeline proposes one, refuse it and flag. These block purchase-intent traffic.
- Never re-propose an existing negative (account-wide 'medicube'; PMax The Body Shop + Standard Beauty). If the full existing-negatives list is not supplied, still ship the CSV but stamp 'could not de-duplicate — verify before bulk upload'.
- Always use the 'Conversions' column, never 'All conversions' (194 phantom GBP conversions inflate it). Afrikaans search terms are themselves a negative signal (English-only audience) -> propose negation.
- KS_C8_Brand_Protection catching a competitor reverse-query is a DEFENSIVE signal, not waste -> surface to T, do not auto-negate.
- Opportunity keywords: only QUALIFIED generics (brand / ingredient / concern qualifier present) — never bare generics; and NEVER propose a keyword for a brand BoT doesn't stock (Round Lab, Torriden, Numbuzin, TIRTIR, Dr. Jart+, Innisfree, Klairs, Isntree, HaruHaru Wonder, Missha, Etude, Heimish, Benton).
- Rank add-candidates by the Secret Skin weakness they exploit: prioritise confirmed gaps (cosrx SA, korean sunscreen SA, beauty of joseon sunscreen SA, snail mucin SA) and the uncontested SA-brand moat (Search_LocalBrands). Head-to-head terms where Secret Skin is strong (korean skincare SA ~3, anua SA ~2, k-beauty SA ~6) get differentiation, not a bid war.
- Channel autonomy is absolute: Google Ads negatives AND add-candidates are CSV/step-list/script deliverables only — recommend-only, never 'applied', never a fabricated account number. Meta exclusions (negative kw / placement / audience) auto-apply within guardrails; escalate any Meta adset >R500/day and never pause here (hand pause calls to bleeder-detection / PPC audit).
- Meta guardrail arithmetic (restated even though this agent mainly excludes): budget change <=20% per run; pause only if adset >=7d old AND >=R300 spend AND 0 conv — this agent does none of these, it only adds exclusions and flags; never delete, never change pixel/CAPI.
- Shopify meta-attribute auto-apply only when the term has no existing coverage AND agents 02/03 haven't already claimed it today; otherwise route via Handoff to avoid double-editing the same collection.

- Google Ads add-candidate keyword list (term + suggested match type + suggested ad group/campaign + landing URL + Secret Skin gap exploited) — recommend-only; human adds via Editor. New ad groups also need RSAs (route to rsa-generator).
