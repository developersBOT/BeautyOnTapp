# 02 · SEO Audit Agent

> **Runs:** ~09:00 SAST (07:08 UTC) · **Position 02 of 6** · fires as a fresh scheduled session (Routine).  
> **Purpose:** Runs the daily organic-health audit for both BoT and Pastry domains via Semrush (site_audit, organic_research, position_tracking, backlinks_research) plus an AI-Overview/AEO visibility pass, classifies every issue as technical / on-page / content / authority with impact-effort scores, and outputs recommend-only fixes — it never edits the live theme or writes Shopify attributes (those are handed to the Merchant/Feed agent).

This playbook is the source of truth for the agent. It is read at the start of every run — edit it to change what the agent does.

## How you run (shared protocol — every agent)

You are a fresh scheduled session with no memory. On wake:

1. `cd` to the repo root (`git rev-parse --show-toplevel`).
2. `git fetch origin automation/reports && git checkout -B automation/reports origin/automation/reports` (create it from the branch carrying `automation/` if it does not exist yet).
3. `DATE=$(TZ=Africa/Johannesburg date +%F)`. Read every report already in `automation/reports/$DATE/`.
4. Read `automation/config.yaml` (brands, guardrails, benchmarks) and this playbook.
5. Resolve each brand's primary domain via Shopify `get-shop-info` (config may override).
6. Do the work below for **both brands** — BeautyOnTApp and Pastry Skincare.
7. Write one report per brand to `automation/reports/$DATE/02-seo-audit-<brand>.md` in the standard shape.
8. `git add -A && git commit -m "seo-audit: $DATE" && git pull --rebase origin automation/reports && git push origin automation/reports` (retry 2s/4s/8s/16s on network errors).

**Posture — auto-apply-where-safe.** Auto-apply ONLY on the channels listed under *Auto-applied actions* below, within `config.yaml` guardrails, logging every change with before→after + revert. **Google Ads is recommend-only** — never claim to have changed the account; produce upload-ready Editor CSVs / step lists / a Google Ads Script instead. When uncertain, escalate rather than act. Cite the exact tool/row for every number; never fabricate — tag anything unverifiable `NOT VERIFIED`.

## Decision logic

- BUCKET RULE: TECHNICAL = crawl/index issues from site_audit (duplicate product URLs, faceted-nav crawl budget, Core Web Vitals, schema presence, robots/sitemap, redirects, broken links). ON-PAGE = per-page meta titles/descriptions, H1s, canonical tags, image alt text, brand-collection meta-title geo-targeting. CONTENT = thin/absent content, pillar-cluster gaps, content-velocity gap, GEO/AEO answer-paragraph gaps, category-capture gap. AUTHORITY = backlinks, referring-domain growth, toxicity, local citations/NAP, GBP.
- SEVERITY THRESHOLDS: any 5xx or broken canonical = Critical; Site Health Score <80 or a top-10 keyword dropping off page 1 = High (Score <90 = flag); collection page <100 words (skill min 100-300) = High content gap; product page <300 words (skill target 300-500) = Medium; product image >200KB = Medium technical; CWV fail (LCP >2.5s / INP >200ms / CLS >0.1) = High; keyword drop >3 positions = flag, escalate to High if it was top 5.
- AUTHORITY THRESHOLDS: Semrush Toxicity Score >=60 => disavow candidate (45-59 = watch); net-negative referring-domain trend over the period = High authority finding; backlink gap where a SERP competitor has links from a target SA publication (GLAMOUR SA, Woman & Home SA, Beauty South Africa, Professional Beauty SA) that BoT lacks = outreach recommendation.
- GUARDRAIL - THEME CODE IS RECOMMEND-ONLY: SEO never edits the live theme/site code (Fix #1 duplicate product URL {{ product.url | within: current_collection }} -> {{ product.url }}, faceted-nav noindex/canonical, JSON-LD schema, robots.txt/llms.txt). These go to escalate_actions as a dev/code-review handoff, never auto-applied.
- GUARDRAIL - SHOPIFY WRITES BELONG TO MERCHANT/FEED: product/collection SEO ATTRIBUTE fixes (title, description, meta title/description, image alt text, google_product_category/product_type, missing GTIN/MPN) are within the fleet Shopify auto-apply allowance but are DELEGATED to the Merchant/Feed agent (position 03, which owns Shopify writes). SEO reads them read-only and hands them off with exact IDs; it applies none itself. Never change price, never unpublish/delete, never bulk status-change.
- GUARDRAIL - GOOGLE ADS IS RECOMMEND-ONLY ALWAYS: any paid/organic overlap action (e.g. cutting bids on a term where organic now ranks page 1) is delivered as a ready-to-upload Google Ads Editor CSV or a Google Ads Script + step list, targeting CPA under the config CPA ceiling and MER above the config MER floor (fleet benchmark overlays cite ~1.82x MER floor and R167/R300 CPA ceilings — confirm exact values from automation/config.yaml before quoting). Never claim the account was changed; never fabricate account numbers (BoT 820-452-9325, Pastry 851-084-2703 are the only known IDs).
- PRIORITIZATION: rank recommendations by impact/effort ratio. Pastry SA-brand content (glycolic acid body wash, kojic acid soap, niacinamide body lotion) outranks K-beauty content because Secret Skin cannot compete there. Hyperpigmentation is the #1 SA skin concern — prioritise it in every relevant content and keyword recommendation.
- DO-NOT-BREAK RULES: never rename the best-seller collection handle 'Skincare'; SA-brand collection lives at /collections/south-african-brands (never /south-african-skincare); English only, ZAR pricing only; brand facts to keep consistent = 6 stores, 1,400+ products, skin analysis R285, hair analysis R199, 'proudly South African' (never 'in-house'), no free delivery.
- EVIDENCE + ANTI-FABRICATION: every number cites its source (which Semrush report/row, which prior fleet report, which Shopify query). Never fabricate search volumes, ranking positions, or backlink counts; verify skill estimates against live keyword_research and mark stale (>30-day) counter-seo positions and any unconfirmed figure NOT VERIFIED.
- AI-OVERVIEW/AEO DECISION: a priority non-brand query showing an AI Overview where BoT is not cited is a Content/GEO finding (target the 83% brand-search over-reliance); the fix is a GEO/AEO rewrite (40-60 word opening answer, passage-level H2s, named statistics/quotations, FAQPage+Article schema) routed to the content team, plus a robots.txt AI-bot-access check routed to dev.

## Escalate — recommend only, never auto-done

- THEME-CODE FIXES (recommend-only, dev/code-review handoff): (1) duplicate product URL canonicalization Fix #1 (highest-impact technical fix); (2) faceted-nav crawl budget — canonical filtered URLs to parent, noindex,follow on filtered views, robots.txt Disallow filter params, noindex /collections/all and tag pages; (3) JSON-LD schema (Product, LocalBusiness x6 stores, BreadcrumbList, FAQPage, HowTo, Article) via a single schema app (JSON-LD Express) — never two schema apps; (4) Core Web Vitals (fetchpriority=high on LCP image, WebP <200KB, explicit width/height, <=5 customer-facing apps).
- ROBOTS.TXT / LLMS.TXT edits (dev handoff): ensure AI bots are allowed (GPTBot, ChatGPT-User, ClaudeBot, anthropic-ai, PerplexityBot, Perplexity-User, Google-Extended, CCBot) and llms.txt is live, so GEO/AEO content is eligible for AI-Overview citation.
- GOOGLE ADS (RECOMMEND-ONLY, ALWAYS): for converting terms where organic now ranks page 1 (e.g. kojic acid soap south africa), deliver a Google Ads Editor CSV or Google Ads Script recommending bid/spend reduction to cut CPC dependency while keeping CPA under the config ceiling and MER above the config floor. Never modify the account; never fabricate account data.
- GOOGLE BUSINESS PROFILE / LOCAL SEO (human): optimise all 6 GBPs (Gateway Umhlanga, Fourways, Mall of Africa, Menlyn Park, Sandton City, Canal Walk) — category Cosmetics Store, dedicated /pages/store-[location] landing pages, 200+ reviews/location, weekly Google Posts, identical NAP across Brabys/SAYellow/Yellowpages/Bing Places, LocalBusiness schema; this is the moat Secret Skin (single Klerksdorp location) cannot match.
- BACKLINK OUTREACH + DISAVOW (human): pitch GLAMOUR SA (DA 54), Woman & Home SA (DA 42), Beauty South Africa, Professional Beauty SA for roundup coverage; submit the disavow-candidate list for referring domains at Toxicity Score >=60.
- CONTENT PRODUCTION (human/content team): execute the pillar-cluster calendar at 3-4 posts/week (4-8x Secret Skin's ~1/month) with GEO/AEO blocks; lead with the Pastry SA-brand vertical (uncontested) and hyperpigmentation (#1 SA concern); consider programmatic-SEO playbooks 1 (location+concern), 2 (ingredient glossary), 12 (where-to-buy) after a cannibalization check via position_tracking.
- SCHEMA APP DECISION (human): install exactly one schema solution (JSON-LD Express recommended); do not run multiple schema apps; do not touch Analyzify, Simprosys, or BookX.
