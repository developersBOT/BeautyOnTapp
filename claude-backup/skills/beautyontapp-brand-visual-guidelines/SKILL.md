# Brand Visual Guidelines for PNCapital

Three brands, one portfolio. Each brand needs a distinct visual identity that stands alone AND works together. Bash uses TFG's generic retail design system. BeautyOnTApp's visual identity must be unmistakably beauty-specialist — every touchpoint should feel curated, not mass-market.

## HARD RULES
1. Brand emoji: 🖤 only. No other emojis in brand contexts.
2. Each brand's visual identity is distinct — never blend palettes or typography between brands.
3. When brands appear together (cross-sell, portfolio view), use a neutral frame (white/black) with each brand's elements inside.
4. All visual assets must work at mobile-first dimensions. SA is 70%+ mobile.
5. All brand palettes and typography below are PROPOSED based on brand positioning. VERIFY with T before production use.

## BEAUTYONTAPP — LUXURY K-BEAUTY CURATOR

### Color Palette (PROPOSED)
| Name | Hex | Usage |
|---|---|---|
| Obsidian Black | #1A1A1A | Primary — headlines, nav, footer |
| Gold Accent | #C8A951 | CTAs, highlights, premium badges |
| Clean White | #FFFFFF | Backgrounds, breathing space |
| Soft Cream | #F5F0EB | Secondary background, cards |
| Text Gray | #4A4A4A | Body text, descriptions |

### Typography (PROPOSED)
- Headlines: Modern serif (e.g., Playfair Display, Cormorant Garant) — luxury feel
- Body: Clean sans-serif (e.g., Inter, DM Sans) — readability
- VERIFY: Check current Shopify theme (Essence 4.1.0) font settings before changing

### Photography Direction
- Clean, minimal backgrounds (white or soft cream)
- Product-forward hero shots with subtle shadows
- Lifestyle: diverse SA women, natural light, real skin textures
- Never over-edited skin — authenticity is the brand
- In-store photography: warm lighting, organized shelves, consultation moments

### Logo Usage
- Minimum clear space: 1x logo height on all sides
- Minimum size: 120px wide for digital, 25mm for print
- Never stretch, rotate, or recolor the logo
- Dark background: use white/light version. Light background: use dark version.

## CROSS-BRAND VISUAL SYSTEM

### When Brands Appear Together
- Use a neutral frame: white or black background
- Each brand occupies its own visual space with its own palette
- Shared heading: "The PNCapital Beauty Portfolio" or "From the BeautyOnTApp family"
- Never merge palettes — a Pastry product should never appear with BeautyOnTApp's gold

## DECISION RULES

1. **When creating any visual asset**: Check which brand it's for. Use ONLY that brand's palette and typography.
2. **When uncertain about brand palette**: Use VERIFY-flagged values as starting point. Confirm with T before any customer-facing use.
3. **When building the Shopify theme**: Essence 4.1.0 theme settings should be configured to match BeautyOnTApp visual guidelines. Pastry and Mzuri have separate Shopify stores with their own themes.
4. **When Bash's visual identity evolves**: Bash uses TFG's generic retail design. BeautyOnTApp's luxury-specialist visual identity is a moat — maintain the gap.
5. **When producing cross-brand content**: Neutral frame, distinct brand zones. Never blend.
