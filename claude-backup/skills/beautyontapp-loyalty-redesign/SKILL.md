# Loyalty Program Redesign for BeautyOnTApp

OneLoyalty has been replaced by Toki Pay-as-you-Go (Skin IQ Club program). TFG has 20M+ Rewards members. Clicks ClubCard is SA's most established beauty loyalty program. BeautyOnTApp needs a loyalty program that creates switching costs Bash and Clicks can't replicate — rooted in beauty expertise, not just points.

## HARD RULES
1. No free delivery as a loyalty perk. Ever.
2. Points must work across all 3 brands (BeautyOnTApp, Pastry, Mzuri).
3. In-store and online earning must be unified via Shopify POS.
4. Tiered system — not flat. Aspirational tiers drive engagement.
5. Beauty-specific rewards (skin analysis, exclusive launches) > generic discounts.

## PROGRAM STRUCTURE: "GLOW REWARDS" (PROPOSED — name and tier names require T's approval)

### Earn Mechanics
| Action | Points earned |
|---|---|
| R1 spent online or in-store | 1 point |
| Write a product review | 50 points |
| Refer a friend (who purchases) | 200 points |
| Complete skin analysis (R285) | 100 points |
| Birthday month | 150 bonus points |
| Share UGC on Instagram (tagged) | 75 points |
| Complete skincare quiz | 25 points |

### Redeem Mechanics
100 points = R10 store credit. Simple. No complex conversion.

### Tier Structure

| Tier | Points/year | Benefits |
|---|---|---|
| Glow (entry) | 0-999 | Earn 1pt/R1, birthday bonus, welcome gift |
| Radiance | 1,000-2,499 | 1.25pt/R1, free skin analysis annually, early access to sales |
| Luminous | 2,500-4,999 | 1.5pt/R1, free skin analysis quarterly, exclusive launches, priority same-day delivery |
| Icon | 5,000+ | 2pt/R1, free monthly sample box, annual VIP event, dedicated beauty advisor, first access to new brands |

### Why Tiers Beat Flat Programs
- **Clicks ClubCard**: Flat cashback. No aspiration. No switching cost.
- **TFG Rewards**: Points on purchases. Not beauty-specific. No expertise layer.
- **Glow Rewards**: Beauty expertise embedded in tiers. Skin analysis, beauty advisor access, and exclusive launches can't be replicated by mass retailers.

## SWITCHING COST DESIGN

The loyalty program must create costs of switching to Bash/Clicks:
1. **Points balance**: Accumulated points create inertia
2. **Tier status**: Losing Luminous/Icon status hurts psychologically
3. **Skin analysis history**: Personalized recommendations based on past analyses
4. **Routine data**: "Your routine is tracked here. Start over there?"
5. **Community membership**: Bestie Squad access tied to loyalty tier

## DECISION RULES

1. **OneLoyalty replacement DECIDED**: Toki Pay-as-you-Go selected (~R920/mo). Program = Skin IQ Club, tiers Glow / Radiance / Luminary. Hero redemption R1,200 free skin analysis (LOCKED — above AOV deliberately). Skill kept for reference on the evaluation framework used.
2. **When comparing to Clicks ClubCard**: Never compete on cashback rate. Compete on beauty-specific rewards.
3. **When TFG Rewards integrates fully with Bash**: Their 20M members is an unfair advantage. Counter with depth (Icon tier perks no mass program offers).
4. **When a loyal customer shops at Bash**: Loyalty data shows they're still earning. The tier progression and upcoming rewards keep them anchored.
5. **When measuring ROI**: Track loyalty member AOV vs non-member. Target: 25%+ higher AOV for loyalty members.
