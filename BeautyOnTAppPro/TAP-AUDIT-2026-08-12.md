# Tap-by-tap fetch & loading audit — BeautyOnTAppPro 1.1.3 (55)

Every interactive control traced to the network call it triggers and the
loading UI it can show. Audited 2026-08-12 against the build-54 source, with
the fixes shipped in build 55 applied where marked ✅.

Legend — **fetch class**:
- `SWR` stale-while-revalidate via `StorefrontResponseVault` (disk): paints
  instantly from last-known-good, refreshes silently. *New in build 55.*
- `MEM` AppModel in-memory cache (5 min TTL, request coalescing) in front of
  the client.
- `LIVE` intentionally network-only (transactional or real-time data).

## Bag / Checkout

All cart operations (`CartView.swift:236,851`, quantity steppers, note,
delivery estimate, checkout handoff) are **LIVE by design** — a bag must
never render from disk. Busy states are button-local. No change.

## Booking (Smart Analysis flow)

`BookingFlowView` fetches live BookX availability (`:204 "Refreshing
availability…"`) and reservation holds — **LIVE by design**; a stale
timeslot is worse than a spinner. Button-local busy states kept.

## Search

Search-as-you-type is **LIVE** (`SearchView.swift:44-72`); previous results
stay on screen while typing (only appends show a spinner). Correct as is.

## Profile / Account

Session probe and OAuth are **LIVE** (identity). The profile sheet itself is
static rows — no fetch, no spinner. Sign-out/dock name refresh preserves the
last verified identity while probing (`AppModel.refreshCustomerSession`).

## Web flows (checkout, Ask Bestie, policies)

WKWebView with its own progress treatment (`WebFlowView.swift:102`,
`RootView.swift:194` cover fallback). Out of scope for native caching.

---

## Remaining intentional loading states

1. Money/transactional: cart mutations, checkout, Buy Now, booking holds.
2. Real-time truth: booking availability, live search, variant availability.
3. True first run (empty vault) and >72h-stale content (vault refuses, by
   design, to present week-old catalogue silently).
4. Pagination tails (footer spinner while appending).
