# Pastry Skincare Meta Ads and Reels audit (2026-09-06)

Investigation-only package. No live changes were made to any Meta, Shopify, catalogue, Pixel or social asset.

- `REPORT.md` – findings, baseline, creative review, test plan, proposals, audits.
- `evidence/derived/` – CSV/JSON tables (every row carries a `source` column).
- `evidence/raw/` – verbatim connector responses (ad sets, ads, creatives, daily series, activity logs, pixel stats, field catalogue).

Rules used: `NOT IN SOURCE` = value absent from an inspected source; `NOT VERIFIED` = claim that could not be checked from this environment.
